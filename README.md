# FitGym - Sitio Web de Gimnasio con Técnicas CSS Avanzadas

## Descripción
Sitio web moderno y responsivo para un gimnasio, desarrollado con HTML5, CSS3 avanzado y JavaScript vanilla. Incluye técnicas de CSS de vanguardia como Custom Properties, Clip-path, Scroll Snap, Modo Oscuro, Glassmorphism y efectos de animación avanzados.

## Páginas Implementadas

### 🏠 Página Principal (index.html)
- Hero section con video de fondo
- Contador animado con estadísticas
- Clases destacadas con efectos hover
- Carrusel de testimonios CSS
- Footer completo con mapa y newsletter

### 🏃 Página de Clases (clases.html)

## Instalación y Uso

### Requisitos
- Navegador web moderno
- Visual Studio Code (recomendado)
- Extensión Live Server (recomendado)

### Instrucciones
1. Abrir la carpeta del proyecto en VS Code
2. Instalar la extensión "Live Server" si no la tienes
3. Click derecho en `index.html` → "Open with Live Server"
4. El sitio se abrirá automáticamente en tu navegador

### Sin VS Code
1. Simplemente abre el archivo `index.html` en tu navegador web
2. Todas las funcionalidades estarán disponibles

```javascript
element.addEventListener('mousemove', function(e) {
    const rect = element.getBoundingClientRect();
    const x = e.clientX - rect.left - rect.width / 2;
    const y = e.clientY - rect.top - rect.height / 2;
    
    const moveX = x * 0.1;
    const moveY = y * 0.1;
    
    element.style.transform = `translate(${moveX}px, ${moveY}px) scale(1.02)";
});
```

```css
    animation: rollUp 0.6s ease-out;
}

@keyframes rollUp {
    from { transform: translateY(100%); }
    to { transform: translateY(0); }
}
```

```javascript
function animateCounter(element) {
    const target = parseInt(element.getAttribute('data-target'));
    const duration = parseInt(element.getAttribute('data-duration')) || 2000;
    let current = 0;
    const increment = target / (duration / 16);
    
    const timer = setInterval(() => {
        current += increment;
        const value = Math.floor(current);
        
        // Efecto rolling para cada dígito
        element.innerHTML = value.toString().split('').map(digit => 
            `<span class="rolling-number">${digit}</span>`
        ).join('');
        
        if (current >= target) {
            element.textContent = target + (element.getAttribute('data-suffix') || '');
            clearInterval(timer);
        }
    }, 16);
}
```
